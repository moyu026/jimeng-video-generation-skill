# HTML Diagram 模块

## 何时读取

当用户选择“将原图按原结构重绘为 HTML 动态图解”，或要求调试已有 HTML 图解时读取。

## 输入

- 原图 / 架构图 / 流程图 / 机制图 / 产品截图
- 原文中对该图的上下文说明
- `shot-list.md` 中对应镜头描述（如有）
- 用户反馈截图或文字反馈（调试阶段）

## 输出

```text
assets/html/<diagram-id>.html
```

## 工作步骤

1. 识别原图类型：分层结构、金字塔、流程图、架构图、关系网络、对比图、指标说明图。
2. 提取结构：主标题、模块、层级、位置、箭头 / 连线 / 流向、说明区、底部价值句。
3. 保留版式：原图是金字塔就保持金字塔；原图是流程图就保持流程方向；原图是关系网络就保持节点和边。
4. HTML/CSS 重建：每个模块为独立 DOM，默认 16:9 `.stage`。
5. 添加可控动效：模块按叙事逻辑出现，箭头 / 连线按流向出现，关键模块可扫光或轻微放大。
6. 调试阶段优先局部修改 CSS 和少量 DOM，不重写整体结构。

## 布局规范

- 默认 16:9 stage：`.stage { width:min(100vw,calc(100vh * 16 / 9)); aspect-ratio:16/9; }`
- 所有布局基于 `.stage` 实际内容区域，不基于显示器物理分辨率硬编码。
- 横向流程图、阶段流、模块流必须使用 CSS Grid 管理模块和箭头。
- 箭头 / 连接线必须作为独立 Grid 列或 Grid 行，例如：`模块 | 箭头 | 模块 | 箭头 | 模块`。
- 不要让模块使用 Grid，而箭头脱离布局后用 absolute + left 百分比反复猜位置。
- 金字塔 / 分层图可使用 absolute 定位，但仍必须基于 stage 内部坐标。
- 关系网络图必须统一坐标系统，节点和连线层级明确。

## 信息完整性

- 默认保留原图文字信息，不主动压缩、改写或删除关键说明。
- 不允许依赖 `overflow:hidden` 裁掉关键文字；`overflow:hidden` 只能用于扫光、光效、装饰元素。
- 文字溢出时优先：扩大模块或说明区域、调整 Grid 比例、减小字号、减小 padding、调整行距、增加模块高度。
- 只有用户明确允许“精简 / 压缩文字”时，才压缩文案或删减 bullet。
- 不默认额外添加 takeaway 标签项，除非原图本身已有或用户明确要求。

## Replay 控制项

- Replay 不应影响录屏构图。
- 默认隐藏或极弱化。
- 必须支持键盘按 `R` 重播。
- 鼠标 hover 到右下角时才淡淡显示 Replay。

推荐实现见 `templates/html-diagram-template.html`。

## 关系网络图 / 多箭头图规则

- 统一坐标系统；若节点是 HTML DOM，关系线也优先使用 HTML/CSS 线段。
- 多箭头关系网络图不优先使用 SVG marker。
- 连线从节点边缘到节点边缘，不穿过节点中心。
- 箭头头部停在节点外侧或边缘，不能压住节点文字。
- 为多条边分配不同通道，避免挤在中心区域。
- 区分实线、虚线、细线语义。
- 箭头头部建议 8–12px，线条层级低于节点。
- 不要为同一对节点重复绘制多余边。

## 反馈调试规则

- 优先局部修改，不重写整体。
- 保持原图结构稳定。
- 保持已有动画逻辑稳定。
- 优先解决文字完整显示、箭头遮挡、模块裁切、底部说明被挡。
- 每次修改后说明改动点，并提示刷新页面或按 `R` 重播。

## 完成标准

- HTML 是单文件，可直接浏览器打开和录屏。
- 保留原图信息结构和版式关系。
- 文字完整显示。
- 流程图箭头纳入 Grid。
- Replay 默认隐藏，按 `R` 可重播。
- 底部说明、价值句、控制项互不遮挡。

## 失败 / 退化路径

- 原图信息过密且无法完整重绘：建议改用“复用原图 + 统一背景图”。
- DOM 结构无法表达原图关系：允许重构 DOM，但需说明原因。
- 用户明确要求视觉创新：仍需保留原图关系语义。
