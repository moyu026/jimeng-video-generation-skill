# Subtitles 模块

## 何时读取

当配音音频已生成或用户提供最终音频，并确认需要生成 / 校准 SRT 字幕时读取。

## 输入

- `narration.md`
- `assets/audio/voiceover.mp3` 或用户提供的最终音频
- 最终镜头时长、剪辑时间线或 `shot-list.md`

## 输出

```text
subtitles/subtitles.srt
```

## 工作步骤

1. 确认最终音频已经存在。
2. 获取音频总时长；必要时使用 ffprobe / 剪辑软件信息。
3. 按 `narration.md` 语义切分字幕，避免单条过长。
4. 根据音频时长和镜头时间线生成 / 校准时间码。
5. 输出标准 SRT。
6. 将字幕路径写入 `asset-manifest.md` 或 `edit-guide.md`。

## SRT 规则

- 从 `00:00:00,000` 开始。
- 时间连续、不重叠。
- 格式兼容主流剪辑软件。
- 字幕不宜过长，长句应拆分。
- 无配音段不生成字幕，或明确标记为无声过场。

## 完成标准

- `subtitles/subtitles.srt` 存在。
- 时间轴与最终音频和镜头时长一致。
- 无重叠、无倒退、无异常空洞。

## 失败 / 退化路径

- 音频不存在：回到 Audio 模块。
- 无法获取音频时长：请求用户提供时长，或生成草稿 SRT 并明确标记。
- 文稿和音频不一致：要求用户确认以音频还是文稿为准。

## 自检清单

- [ ] 是否在最终音频后生成？
- [ ] 是否从 00:00:00,000 开始？
- [ ] 是否连续不重叠？
- [ ] 是否兼容标准 SRT？
