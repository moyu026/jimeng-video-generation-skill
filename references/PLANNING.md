# Planning 模块

## 输入与输出

输入用户提供的发布稿、产品文档、Markdown、截图、架构图、流程图、录屏和参考风格。输出：

需要保存到项目的补充文档、截图、架构图、流程图和用户原始视频统一放入 `assets/original/`；向用户索取时同时说明该路径。

```text
video-plan.md
narration.md
shot-list.md
```

规划阶段不生成音频、视频或最终字幕。开始规划前必须先确认：横屏 `16:9`（`1920×1080`）或竖屏 `6:7`（`1080×1260`）。

## 固定镜头结构

1. `S00`：封面图循环帧，配音为开场介绍，对应 `audio0.mp3`。
2. `S01...`：根据用户材料规划的主体镜头。
3. 最后一个 Shot：`outro`，视频由用户提供，配音使用固定文案。

固定 outro 文案：

```text
openJiuwen开源社区致力于打造精准、易用、高效的生产级AI Agent。欢迎大家持续关注公众号后台回复开源加入开发交流群，解锁更多实用的智能体案例与前沿技术干货.
```

Shot ID 从 `S00` 连续递增，不跳号。每个 Shot 必须对应 `audioN.mp3`。

## 工作步骤

先把用户确认的画面方向、比例和分辨率写入 `video-plan.md` 与 `shot-list.md`，再执行：

1. 从原材料提取主题、受众、关键问题、核心机制、最强案例、边界和价值。
2. 生成 `video-plan.md`，说明目标、结构、时长、镜头策略和交付物。
3. 先写唯一配音总稿，再按 Shot ID 原样切分到 `narration.md` 的分镜映射。
4. 为 `S00` 编写封面配音；把固定 outro 文案作为最后一段配音。
5. 生成 `shot-list.md`，将同一份分镜配音逐字同步进去。
6. 在 `shot-list.md` 中写完整封面图 Prompt，并明确封面图将生成 `S00.mp4` 循环帧。
7. 主体镜头优先规划为 `jimeng-video`；每个即梦原始视频生成 6–8 秒，并写逐 1–2 秒时间轴 Prompt。
8. 只有用户提供架构图 / 流程图，且该结构无法用即梦清楚表达时，才规划 `html-recording`；整条视频最多 3 个 HTML 录屏。
9. 将最后一个镜头标记为 `user-provided-outro`，不为它调用即梦生成。
10. 不规划后期图文包装；删除大字标题、箭头、框选、Logo、UI 标签或画面文字叠加建议。
11. 将每段最终时长标记为“以对应 audioN 为准”；总时长以全部分段音频之和为准，允许后续变速视频。
12. 运行配音一致性检查。

## shot-list.md 必填列

```markdown
| Shot ID | 板块 | 素材类型 | 生成时长 | 最终时长依据 | 画面设计 | 视频 Prompt / 执行说明 | 配音文案 | 视频文件 | 音频文件 | 状态 |
```

素材类型只使用：

- `cover-still`：仅限 `S00`。
- `jimeng-video`：主体默认素材；每个原始视频生成 6–8 秒，最终按 audioN 变速。
- `source-video`：复用用户原始视频或录屏。
- `html-recording`：仅当用户提供架构图 / 流程图且即梦无法清楚表达时使用，整条视频最多 3 个；必须写明动画时长 A、录屏时长 A+1 秒、底部 18% 字幕安全区和 `record_html_with_ffmpeg.py` 输出路径。
- `user-provided-outro`：仅限最后一个 Shot。

AI 视频 Prompt 必须写明已确认的横屏 `16:9` 或竖屏 `6:7`，原始生成时长必须为 6–8 秒，并包含逐 1–2 秒变化、镜头运动、结尾状态、风格和禁止内容。原始生成时长不等于最终片段时长，最终时长由对应 audioN 决定。禁止生成可读文字、Logo、真实代码、品牌标识、字幕、真实人物或人物背影。

## 封面 Prompt

封面 Prompt 直接写入 `shot-list.md`，至少包含：

```text
封面目标：
当前产品 / 技术名称：
画面方向与比例：<横屏 16:9（1920×1080）/ 竖屏 6:7（1080×1260）>
主体构图：
技术隐喻：
视觉风格：
色彩与光效：
禁止内容：禁止错误文字、第三方 Logo、水印和真实人物。
输出路径：assets/covers/cover.png
视频化：根据 audio0.mp3 时长循环该图片，输出 materials/MP4/S00.mp4
```

封面是视频第 0 段，不再视为时间线外资产。

## 配音一致性

`配音总稿` 只包含可朗读正文。按 Shot ID 拼接所有分镜配音并去除空白后，必须与配音总稿一致；`shot-list.md` 同 Shot 的配音必须逐字相同。

运行：

```bash
python scripts/check_narration_consistency.py --narration narration.md --shot-list shot-list.md
```

## Checkpoint

规划完成后必须让用户检查 `narration.md` 和 `shot-list.md`。有修改就同步修改并重跑校验；用户确认无需修改时保持文件不变，进入音频准备。

## 完成标准

- 画面方向已由用户确认，所有 Prompt 和输出尺寸保持一致。
- `S00`、主体镜头、最后的用户 outro 都存在且编号连续。
- 主体镜头以 6–8 秒 `jimeng-video` 为主；HTML 录屏仅在两个前置条件同时满足时使用且不超过 3 个。
- 每段最终时长以 audioN 为准，视频总时长以全部分段音频之和为准。
- `shot-list.md` 包含封面 Prompt 和每段视频 / 音频文件名。
- `narration.md` 包含封面配音和固定 outro 文案。
- 没有后期图文包装。
- 配音一致性检查通过。
