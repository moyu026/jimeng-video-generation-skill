# Planning 模块

## 何时读取

当用户要求生成即梦视频脚本、技术发布短视频规划、分镜、配音稿、AI 视频 Prompt，或完整端到端流程的第一步时读取。

## 输入

- 发布稿 / 产品文档 / Markdown / 技术文章
- 截图、录屏、架构图、流程图、机制图等素材
- 用户指定的视频目标、受众、比例、风格；未指定时默认 16:9、个人技术分享风格
- 如有历史参考脚本，可作为分镜结构、素材混用方式和后期建议风格的参考，但不能照抄具体内容

## 输出

规划阶段只输出：

```text
video-plan.md
narration.md
shot-list.md
```

其中 `video-plan.md` 必须包含视频封面图生成 Prompt。

不输出最终 SRT，不调用即梦 / 录屏工具，不生成配音音频。

## 工作步骤

1. 捕获用户意图：确认是完整规划还是单项 Prompt / 单项脚本。
2. 提炼产品叙事骨架：核心功能、用户痛点、旧方式不足、一句话定义、核心变化、核心能力、Wow Moment、适用场景、边界判断、价值升华。
3. 技术观点提取：关键机制、性能收益、边界判断优先参考原文，保留核心术语，不改成泛营销话术。
4. 组织视频结构：默认 Hook / What / How / Future 四段式，时长根据素材复杂度和复用片段动态决定，总时长控制在 150 秒以内。
5. 规划即梦 / AI 生成视频镜头时长：即梦支持 4–15 秒，但生成时间越长越难稳定和调试；默认优先 4–8 秒，信息量稍复杂可用 8–10 秒，只有画面变化很少、节奏很慢或明确需要长镜头时才使用 11–15 秒；复杂表达优先拆成多个短镜头。
6. 判断素材类型：AI 生成视频、原图复用 + 统一背景图、原图转 HTML 动态图解并录屏、原始视频复用、后期图文包装、封面图。
7. 若素材包含原图 / 架构图 / 流程图 / 机制图 / 产品截图，且用户未说明处理方式，必须先询问两个分支：
   - 复用原图 + 生成统一背景图
   - 将原图按原结构重绘为 HTML 动态图解并录屏
8. 生成 `video-plan.md`：视频目标、受众、叙事骨架、章节结构、素材策略、封面图 Prompt。
9. 生成 `narration.md`：完整配音稿 + 分镜配音映射。
10. 生成 `shot-list.md`：剪辑友好的分镜表格，并按素材类型补齐执行说明。
11. 为 AI 视频镜头编写镜头内时间轴 Prompt。

## 分镜脚本撰写规范

`shot-list.md` 是 Planning 阶段最重要的协作接口，需要同时服务：即梦视频生成、HTML 图解制作、原始素材复用、后期剪辑和配音对齐。

默认使用接近真实剪辑表的结构：

```markdown
| Shot ID | 分镜 | 板块 | 时间段 | 素材类型 | 画面设计概述 | 镜头内时间轴 / 素材执行说明 | 配音文案 | 后期建议 | 状态 |
|---|---:|---|---|---|---|---|---|---|---|
```

### 每个分镜必须写清楚

1. **Shot ID**：稳定英文编号，如 `S01`、`S02`，供后续脚本和资产清单引用。
2. **分镜**：人类可读的顺序编号。
3. **板块**：如 Hook / Why、What、How、Wow Moment、Future / Action。
4. **时间段**：如 `00:00-00:08`。所有镜头时间段必须连续，不能漏填。
5. **素材类型**：必须从标准素材类型中选择，必要时组合说明。
6. **画面设计概述**：一句话说明镜头要表现什么。
7. **镜头内时间轴 / 素材执行说明**：根据素材类型写不同内容。
8. **配音文案**：该镜头对应的可朗读口播。
9. **后期建议**：大字标题、标注、箭头、音效、转场、框选等。
10. **状态**：默认 `planned`，后续可更新为 `generating`、`done`、`failed`、`needs-review`。

### 标准素材类型

| 素材类型 | 何时使用 | 规划阶段写法 |
|---|---|---|
| AI 生成视频 | 抽象痛点、概念隐喻、趋势升华、无真实素材的动态场景 | 写完整镜头内时间轴 Prompt |
| 原图复用 + 统一背景图 | 原图信息密度高，需要保留真实可信度 | 写原图来源、背景风格、后期叠放和标注建议 |
| 原图转 HTML 动态图解并录屏 | 架构图、流程图、机制图、分层图、关系图等原图结构清晰 | 写原图来源、HTML 文件名、保留结构、动画顺序、录屏时长、录屏输出路径 |
| 原始视频复用 | 产品演示、录屏、真实操作流程 | 写素材路径、建议截取区间、画面重点、后期标注 |
| 后期图文包装 | 标题、大字、字幕、箭头、框选、Logo、UI 标签 | 写后期添加内容，避免交给 AI 生成可读文字 |
| 封面图 | 视频发布封面、社媒缩略图、B 站 / 视频号封面 | 写封面图 Prompt、构图、主体、风格、后期标题区建议和禁止内容 |

## 不同素材类型的执行说明写法

### 1. AI 生成视频镜头

AI 视频镜头必须写完整“镜头内时间轴 Prompt”，不能只写静态画面。

即梦生成时长策略：

- 支持范围：4–15 秒。
- 默认优先：4–8 秒，更稳定、更容易调试和重生成。
- 谨慎使用：8–10 秒，只用于一个连续概念需要完整起承转合时。
- 尽量避免：11–15 秒，除非画面变化很少、节奏很慢，或用户明确要求长镜头。
- 如果一个镜头需要承载多个动作 / 多层概念，优先拆成多个 4–8 秒短镜头，而不是生成一个 15 秒镜头。

推荐格式：

```text
画面设计概述：<一句话说明镜头目的>
镜头内时间轴：
0–2 秒：<画面主体、元素动作、镜头运动>
2–4 秒：<变化和衔接>
4–6 秒：<变化和衔接>
6–8 秒：<结尾前状态>
结尾画面：<最后 0.5–1 秒定格状态>
风格要求：<画面风格、色彩、光效、质感>
禁止内容：<统一禁止内容>
```

必须避免：

- 可读文字、字母、数字、Logo、品牌标识、真实代码、终端命令、字幕、水印、界面标签。
- 真实人物、人物背影、手部特写，除非用户明确要求。
- 聊天界面中出现头像、真人脸、卡通脸、人物剪影或类似社交软件头像的元素，除非用户明确要求。

建议将文字区域表现为：抽象线条、空白卡片、不可读图标块、伪代码形状、几何图表、灰色短横线、圆点列表占位符、进度条、缩略图占位框。

### 2. 原图转 HTML 动态图解并录屏镜头

涉及 HTML，默认输入是原图 / 架构图 / 流程图 / 机制图，需要完整规划为：

```text
原图 → 按原结构生成 HTML 动态图解 → 浏览器录屏成视频素材
```

该类镜头不需要写 AI 视频式 Prompt，而要写清楚可执行信息：

```text
原图来源：<PDF 页码 / 图片路径 / 截图名称>
HTML 输出：assets/html/<diagram-id>.html
保留结构：<原图中的模块、层级、箭头、说明区、底部价值句>
动画顺序：<按技术逻辑出现的顺序>
录屏时长：<建议秒数>
录屏输出：assets/recordings/<diagram-id>.mp4
```

规划时必须说明：

- 原图结构如何保留。
- 哪些模块需要依次出现。
- 箭头 / 连线按什么流向出现。
- 是否需要后期叠加标题、框选、放大或高亮。

### 3. 原图复用 + 统一背景图镜头

```text
原图来源：<图片路径 / PDF 页码>
背景策略：复用统一技术氛围背景，不预留固定相框
展示方式：<居中 / 左右排版 / 局部放大 / 轻微缩放>
后期标注：<标题、takeaway、箭头、框选、局部高亮>
```

每张原图应生成一句 15 字以内专业 takeaway，像图表标题一样准确概括核心机制。

### 4. 原始视频复用镜头

```text
素材来源：assets/original/<file>.mp4
建议截取区间：<起止时间，未知则写待确认>
画面重点：<这段视频证明什么能力 / 展示什么流程>
处理建议：<裁剪 / 加速 / 静音 / 保留原声 / 局部放大>
后期标注：<大字、箭头、框选、步骤标签>
```

如果单个复用视频镜头配音超过 15 秒，优先考虑拆成多个镜头，或明确该镜头是长演示片段。

### 5. 后期图文包装镜头

所有可读文字、Logo、代码、字幕、UI 标签，默认由后期添加。规划阶段需要写明：

- 大字标题
- 画面金句
- 箭头 / 框选 / 高亮区域
- 音效 / 转场建议
- 字幕样式或位置建议

---

### 6. 封面图 Prompt

Planning 阶段必须生成视频封面图 Prompt，写入 `video-plan.md`。封面图用于视频发布页、社媒缩略图或项目展示，不计入视频时间线。

封面图 Prompt 可以接受参考示例图。参考图可以来自用户上传图片、本地路径或 URL，但只用于参考视觉风格、构图、底色、光效、层次、留白、标题区位置和图标风格，不复制其中的文字、第三方 Logo、第三方品牌、人物或具体受版权保护的元素。

如果用户提供的是自有 / 授权的开源社区 Logo、项目 Logo 或品牌标识，可以在封面图规划中明确“需要露出该 Logo”。但为了保证 Logo 准确性，默认建议把 Logo 作为后期叠加资产处理；若图像生成工具支持参考图 / 图层合成，也可以把 Logo 作为用户提供的授权素材输入，但必须避免让模型凭空重画或篡改 Logo。

封面图 Prompt 必须包含：

```text
封面目标：<这张封面要传达的核心卖点>
参考示例图：<可选，图片路径 / URL / 用户上传图片；没有则写无>
参考重点：<构图 / 底色 / 光效 / 层次 / 留白 / 标题区 / 图标风格>
Logo 使用：<是否需要露出自有 / 授权开源社区 Logo；建议写明 Logo 文件路径，并默认后期叠加>
不参考内容：<第三方文字 / 第三方 Logo / 第三方品牌 / 人物 / 具体产品元素 / 受版权保护元素>
主体构图：<主视觉元素、前景 / 中景 / 背景关系>
技术隐喻：<记忆网络、Agent 节点、架构图、数据流等>
视觉风格：<极客审美、科技感、Excalidraw、深色 / 浅色等>
标题区建议：<是否预留后期加标题的位置；标题文字由后期添加>
色彩与光效：<主色、辅助色、对比关系>
禁止内容：禁止生成任何可读文字、字母、第三方 Logo、第三方品牌标识、真实代码、真实人物或人物背影。封面标题、作者名、平台标签统一由后期添加；自有 / 授权开源社区 Logo 可作为用户提供素材使用，优先后期叠加，不能由模型凭空重画。
```

封面图 Prompt 不应要求 AI 直接生成可读标题文字。需要标题时，只描述“预留标题区域”或“后期添加标题”。如果用户提供参考图，应明确说明“参考其设计方向，不复刻具体内容”。

## AI 视频 Prompt 规则

每个 AI 视频镜头必须包含：

- 镜头总时长
- 整体画面设定
- 逐 1–2 秒画面变化
- 镜头运动方式
- 结尾画面状态
- 风格要求
- 禁止内容

禁止内容固定包含：

> 禁止生成任何可读文字、字母、Logo、真实代码、品牌标识、真实人物或人物背影。所有文字、代码和 UI 标签都必须用抽象线条、空白卡片、不可读图标块、伪代码形状和示意图形表达，文字内容统一由后期添加。

## 配音稿撰写规范

`narration.md` 应同时包含：

1. **配音总稿**：完整、顺畅、可直接朗读。
2. **分镜配音映射**：每个 Shot ID 对应哪段配音。
3. **字数和预估时长**：用于发现单镜头配音过长的问题。

要求：

- 技术观点尽量来自原文。
- 口播自然，但不要牺牲专业性。
- 不要把标题、序号、表格说明写入口播总稿。
- 单镜头口播过长时，优先拆镜头或拆配音节拍。

## 完成标准

- `video-plan.md` 讲清楚视频目标、受众、叙事骨架、总时长估计、章节结构，并包含视频封面图 Prompt。
- `narration.md` 是可直接配音的自然口播稿，专业准确，不含非口播标题说明，并有分镜映射。
- `shot-list.md` 每个镜头都有 Shot ID、分镜、板块、连续时间段、素材类型、画面设计、执行说明、配音文案、后期建议和状态。
- AI 视频镜头 Prompt 具体、可见、可动、可生成，并优先控制在 4–8 秒。
- 原图转 HTML 动态图解并录屏镜头写明原图来源、HTML 文件名、保留结构、动画顺序、录屏时长和录屏输出。
- 原始视频复用镜头写明素材路径、截取区间、画面重点和后期标注。
- 如果包含原图，已经明确用户选择的原图处理分支。

## 失败 / 退化路径

- 素材不足以判断产品 / 功能对象：追问。
- 用户只要求单项 Prompt：只输出 Prompt，不生成完整规划文件。
- 用户要求 SRT：说明最终 SRT 应在用户提供最终音频或最终视频后生成；若只是预览字幕，可明确标记为“草稿字幕”。
- 时间段无法准确估计：先给连续估算时间，并在状态中标记 `needs-duration-confirmation`。

## 自检清单

- [ ] 是否没有在规划阶段生成最终 SRT？
- [ ] 是否体现技术专业度，而不是泛娱乐口播？
- [ ] 是否因为压时长删掉了必要机制解释？
- [ ] 是否明确区分素材类型？
- [ ] 是否展示一个最强 Wow Moment？
- [ ] 所有镜头时间段是否连续？
- [ ] 是否没有漏填时间段？
- [ ] AI 镜头是否包含逐 1–2 秒时间轴和统一禁止内容？
- [ ] 即梦 / AI 生成视频镜头是否优先控制在 4–8 秒，复杂镜头是否已拆分？
- [ ] 原图转 HTML 动态图解并录屏镜头是否写明原图来源、HTML 文件名、动画顺序、录屏时长、录屏输出？
- [ ] 原图复用镜头是否写明原图来源、背景策略、后期标注？
- [ ] 原始视频复用镜头是否写明素材路径、截取区间、后期标注？
- [ ] 单镜头配音是否过长，是否需要拆镜头？
- [ ] 总时长是否包含 AI 视频、HTML 录屏、原始视频复用片段？
- [ ] `video-plan.md` 是否包含封面图 Prompt，且封面文字由后期添加？
- [ ] 原图处理方式是否已经确认？
