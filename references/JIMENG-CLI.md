# Jimeng CLI 模块

## 输入

读取用户确认后的 `shot-list.md`，仅处理素材类型为 `jimeng-video` 的 `S01...` 主体镜头。不要处理 `S00` 或最后的用户 outro。

## 工作步骤

1. 运行 `python scripts/check_environment.py --require-jimeng`。
2. 检查每个 Prompt 是否写明用户确认的横屏 `16:9` 或竖屏 `6:7`，原始生成时长是否为 6–8 秒，并包含逐 1–2 秒时间轴、镜头运动、结尾状态、风格和禁止内容。
3. 调用即梦 CLI；认证或环境缺失时先配置并复检。
4. 将结果保存为 `materials/MP4/<Shot ID>.mp4`，例如 `S01.mp4`。
5. 不添加后期图文包装，不生成可读文字、字幕、Logo 或真实代码。
6. 失败时记录原因并重试；不要用占位空文件冒充成功结果。

## 完成标准

- 所有 `jimeng-video` 镜头均有同 Shot ID 视频文件，比例与用户选择一致，原始生成时长均为 6–8 秒。
- 即梦原始视频时长不决定成片时长；后续按对应 audioN 变速。
- `S00` 由封面脚本生成，最后一个 outro 由用户提供。
- 输出可被素材完整性检查识别。
