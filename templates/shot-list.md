## 分镜自检

- [ ] 所有镜头时间段连续，没有漏填。
- [ ] 总时长包含 AI 视频、HTML 录屏、原始视频复用片段。
- [ ] AI 镜头包含逐 1–2 秒时间轴和统一禁止内容。
- [ ] 原图转 HTML 动态图解并录屏镜头写明原图来源、HTML 文件名、动画顺序、HTML 人工验证状态、录屏时长、录屏输出。
- [ ] 每张 HTML 图解都必须人工打开验证，通过前不进入录屏。
- [ ] 原图复用镜头写明原图来源、背景策略、takeaway 和后期标注。
- [ ] 原始视频复用镜头写明素材路径、截取区间、画面重点、后期标注。
- [ ] `配音文案` 列与 `narration.md` 同 Shot ID 分镜配音逐字一致，没有摘要、改写或另写。
- [ ] 单镜头配音没有过长；如超过 15 秒，已拆镜头或明确为长演示片段，不能摘要改写配音映射。
- [ ] 所有可读文字、Logo、代码、字幕、UI 标签都安排为后期添加。
